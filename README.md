# Картотека — установщики

Здесь публикуются только готовые установщики программы «Картотека» и файл
обновлений `update.json`. Исходный код здесь не хранится.

Программа сама проверяет новые версии по адресу
`https://github.com/germanpreobrazenskij19-code/kartoteka-downloads/releases/latest/download/update.json`
и обновляется по кнопке «Обновить программу».
